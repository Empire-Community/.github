# Política de Segurança — Empire Community

A segurança de nossos projetos, dados de usuários e integridade dos servidores é prioridade máxima em todos os repositórios da **Empire Community**.

## Versões com Suporte de Segurança

Como regra geral, apenas as versões mais recentes das branches principais (`main`) e os lançamentos oficiais ativos recebem correções de vulnerabilidade de segurança.

| Repositório | Versão / Ramo com Suporte |
| :--- | :--- |
| **EmpireMuse** | `main` / Último release |
| **EmpireSite** | `main` / Produção |
| **EmpireGames** / **EmpireEngine** | `main` |
| Demais repositórios públicos | `main` |

## Como Reportar uma Vulnerabilidade (Divulgação Responsável)

**Por favor, NÃO abra issues públicas no GitHub para reportar vulnerabilidades de segurança.**

Para reportar uma falha de segurança de forma responsável e confidencial:

1. **GitHub Private Vulnerability Reporting**: Nos repositórios onde o recurso estiver ativo, acesse a aba **Security** > **Report a vulnerability**.
2. **Contato Direto via E-mail**:
   - Envie os detalhes técnicos para: **contact@empirehub.com.br**
   - Assunto: `[VULNERABILIDADE] Nome do Repositório - Breve resumo`

### Informações Recomendadas no Relatório:
- Descrição clara da vulnerabilidade e impacto potencial.
- Passo a passo para reproduzir a falha (Proof of Concept / PoC), scripts ou payloads de teste.
- Versão do projeto, sistema operacional e ambiente testado.
- Mitigações ou correções sugeridas (se você tiver uma ideia de como solucionar).

---

## Prazo de Resposta e Tratamento

- **Confirmação inicial**: Nos esforçamos para acusar o recebimento em até 48 horas úteis.
- **Investigação e Triagem**: A equipe técnica verificará a falha em ambiente isolado.
- **Correção e Divulgação**: Uma correção será desenvolvida em sigilo e publicada junto a um boletim explicativo e os devidos agradecimentos (*Security Acknowledgments*).

Agradecemos imensamente a todos os pesquisadores e colaboradores que nos ajudam a manter a comunidade segura!
